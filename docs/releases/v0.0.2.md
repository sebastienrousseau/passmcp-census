## Highlights ⭐️

* **A census you can rerun**: `passmcp-census run` checks the MCP Registry's remote servers with a released passmcp, read-only and without credentials, and records the passmcp version, the registry snapshot time and the command that reproduces it.
* **Aggregate figures only**: `passmcp-census aggregate` publishes counts and rates by outcome, check, phase, transport and authorization scheme as CSV, JSON and a Frictionless Data Package, with no server identified.
* **Polite by construction**: Four checks at a time, ten seconds between checks on one host, one request a second within a check, and a deadline per endpoint. No census edition is published in this release.
