## Highlights ⭐️

* **In lockstep with passmcp 0.0.10**: passmcp-census moves to 0.0.10 alongside the 15-repository passmcp family manifest. No census edition is published in this release.
* **The census runs passmcp v0.0.10**: the flags the census passes, the request count and the report fields it reads are unchanged (139 checks across nine phases); `catalog.toxic_combination` excludes closed-world bundled-fixture readers, and `catalog.tools.annotation_honesty` accepts read-only inspection and simulation `run_*` and `execute_*` tools.
* **15-repository family table**: `README.md` lists the six Apache-2.0 MCP language SDK satellites (`passmcp-sdk-go`, `passmcp-sdk-python`, `passmcp-sdk-java`, `passmcp-sdk-cpp`, `passmcp-sdk-typescript` and `passmcp-sdk-rust`) alongside the nine existing components.
