## Highlights ⭐️

* **Fuzzed where the input is untrusted**: The passmcp report reader and the registry page reader now have Go fuzz targets that check no server-chosen name or unusable URL can get through, whatever a report or a registry page holds.
* **Same census, same method**: What `passmcp-census` lists, runs and publishes is unchanged. No census edition is published in this release.
