# Support

| You want to | Go to |
|---|---|
| Stop your server being contacted | [docs/disclosure-log.md](docs/disclosure-log.md#asking-to-be-excluded) |
| Question a published figure | an [issue](https://github.com/sebastienrousseau/passmcp-census/issues) naming the edition and table |
| Report a vulnerability in passmcp-census | [SECURITY.md](SECURITY.md) |
| Understand how a figure is produced | [docs/methodology.md](docs/methodology.md) |

A per-check figure is passmcp's verdict, counted. A verdict that looks wrong
is passmcp's to fix: report it to
[passmcp](https://github.com/sebastienrousseau/passmcp/issues).

passmcp-census is maintained by one person alongside other work. Issues are
read weekly; exclusion requests are acted on before the next edition.
