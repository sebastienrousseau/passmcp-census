# Governance

passmcp-census is one repository in the passmcp family and is governed the
way the family is: one Maintainer, decisions recorded in issues and pull
requests, and the rules in [AGENTS.md](AGENTS.md).

The Maintainer decides:

- **the methodology:** the selection, the phases, the reduction and the
  tables;
- **when an edition runs:** there is no schedule, and every run is started
  and reviewed by hand ([ADR 0003](docs/adr/0003-editions-run-by-hand.md));
- **exclusions:** each request is recorded in the disclosure log.

The census is archived, not left stale, if editions stop being repeated:
that is the criterion the family's ecosystem map records for it.
