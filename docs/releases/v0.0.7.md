## Highlights ⭐️

* **In lockstep with passmcp 0.0.7**: passmcp-census moves from 0.0.5 to the family's version. No census edition is published in this release.
* **Go 1.26.9 or later**: the Go 1.26.8 standard library has nine vulnerabilities that the registry client reaches, all fixed in 1.26.9, so the floor moves up.
* **The census runs passmcp v0.0.7**: `check` flags and report fields are unchanged; `protocol.deprecated_features` now asks for `initialize` as a handshake, which can move that check between warn and pass on a server that speaks a stateless revision.
